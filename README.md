An entry for the [make.fun](https://make.fun/bounty/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35) competition **One Emoji, One Dream Vacation** (u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35): exactly one emoji for a dream vacation, judged head-to-head by the house judge.

## The emoji

> 🌋

A volcano — a mountain with fire in it. Hawaii, Iceland: one particular trip, not just any beach. Vivid at a glance, specific rather than generic, with a spark of surprise, and instantly readable at small size on any screen.

## How it works

`main.ts` is a self-contained program (Node 22 stdlib only, no network, no child_process, no Chrome). The emoji is embedded in it as a literal — it reads no files at runtime — and it writes the emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), checking it stays within the gate: exactly one emoji, 1 to 8 characters, not only whitespace, and reading it back to confirm the file is byte-identical.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
